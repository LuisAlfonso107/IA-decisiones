# AlterEGO - Tu Copiloto Existencial

Una inteligencia artificial revolucionaria que actúa como **copiloto personal** para las decisiones más importantes de tu vida.

## Descripción del Proyecto

**AlterEGO** es una IA avanzada diseñada para acompañarte en la toma de decisiones trascendentales. 

En lugar de consejos genéricos, AlterEGO te dice **qué hacer**, en qué orden y con qué expectativas reales: qué estudiar, dónde vivir, si aceptar o rechazar un trabajo, cuándo terminar una relación, cómo invertir, si tener hijos ahora o esperar, y muchas decisiones más.
